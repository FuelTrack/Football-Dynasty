# Football Dynasty

Football Dynasty is a free-first, browser-based football management and simulation game designed for mobile and desktop.

## Phase 1 goals

- Fictional clubs and players
- Detailed management simulation foundations
- Responsive mobile/desktop UI
- Squad management
- Tactics
- Fixtures and league table
- Event-driven match simulation
- 2D match centre foundation
- Local career saves

## Tech stack

- React
- TypeScript
- Vite
- CSS
- Local browser storage
- GitHub Pages

## Development approach

Phase 1 focuses on a playable vertical slice: create a manager, select a fictional club, manage the squad and tactics, play matches, update the league table, and save progress locally.
